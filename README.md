# open-data-ses-susep
Repositório dedicado à coleta, tratamento, análise e visualização de dados abertos da SES SUSEP

### **Objetivo**
Criar uma arquitetura open-source responsável por realizar a ingestão diária\mensal dos dados, na qual irá atualizar as tabelas de forma incremental dentro do data warehouse. Assim, teremos um ambiente com dados abertos disponíveis para atualizar dashboards, entregar consultas e pesquisas nas fontes.

### **Desenho de Solução**

Foi realizado após a definição da base de dados e estudo de viabilidade de como poderiamos seguir em relação a requisição automatica dos dados.
